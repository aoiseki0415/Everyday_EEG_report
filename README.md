# Everyday EEG Report

毎日1本、脳科学・神経科学領域の英語論文を探索し、日本語で要点をまとめて記録するプロジェクトです。

毎日13時（日本時間）に送られるトリガーメッセージを起点として、Codexが候補論文を幅広く調査します。その中から条件に最も合う1本を選び、Google Drive上の月次Googleスライドへ追記します。

> [!IMPORTANT]
> タスクを開始するときは、必ず最初にこのREADMEの最新版を確認し、記載された探索・共有・保存のルールに従ってください。

## 実行スレッドとトリガー

- **実行スレッド**：同じCodexプロジェクト内の「論文チェック」
- **実行時刻**：毎日13時（日本時間）
- **トリガーメッセージ**：`脳科学・神経科学に関する重要論文を探索し、最適な文献を共有してください`

「論文チェック」スレッド内に上記メッセージが送られたら、その日のタスクを開始します。メッセージを確認したCodexは、論文検索を始める前に、まずこのREADMEを開いて最新版の運用ルールを確認します。

## 目的

- 脳科学・神経科学の新しい研究に毎日触れる
- 運動と脳・神経系の関係について、研究領域を偏らせずに知識を広げる
- EEGを用いた研究を、専門外の手法に寄りすぎない形で理解する
- 調査結果を月単位のスライドに蓄積し、あとから参照しやすくする

## 対象とする論文

必須条件は以下のとおりです。

- 脳科学または神経科学に関係すること
- 英語で書かれた論文であること
- 運動に関係すること
- 原則としてEEGを扱っていること
- 原著論文を基本とし、実際の公開状態と書誌情報を確認できること

運動との関係には、たとえば以下の領域を含みます。

- 運動学習・運動制御
- 運動準備・運動出力
- 感覚運動統合
- 歩行・姿勢・バランス
- スポーツ・身体活動・運動習慣
- 神経リハビリテーション
- BCI、ニューロフィードバック、ニューロテクノロジー
- 疲労、加齢、疾患などが運動機能へ与える影響

## 論文の探索方針

検索は特定のジャーナルや単一の検索結果だけで決めず、PubMed、Crossref、出版社サイト、Google Scholarなど、利用可能な複数の情報源を横断して候補を集めます。検索時点で参照できる範囲をできるだけ広く取り、タイトル、抄録、出版日、ジャーナル、DOIまたは論文URLを一次情報で照合します。

### 選定の優先順位

以下を上から順に重視します。

1. **ジャーナルの水準**：まず、*Journal of Neuroscience* や *Journal of Physiology* と同程度以上の評価を持つジャーナルを探索します。適切な論文が複数ある場合は、Nature系列など、より影響力の高いジャーナルの論文を優先します。該当論文がなければ、研究内容との適合性を保ちながら対象ジャーナルの範囲を段階的に広げます。
2. **運動との関連性**：運動が研究目的、課題、アウトカム、介入、または応用先の中心にある論文を優先します。
3. **EEGの使用**：EEGが主要な計測・解析手法として使われている論文を優先します。fMRIのみを中心とする研究は原則として選びません。

ジャーナル指標は年やデータベースによって変動するため、数値だけで機械的に決定しません。ジャーナルの水準を入口にしつつ、最終的には研究テーマとの適合性、研究の質、新規性、理解しやすさを含めて判断します。

### 公開時期

- 検索実行日から直近6か月以内に公開された論文を優先します。
- 適切な論文が見つからない場合は、探索期間を段階的に広げます。
- online first、early view、正式号掲載などの日付が併存する場合は、それぞれを確認し、採用した出版年・公開日を明確にします。

### 日々の分散

毎日同じテーマが続かないよう、過去に紹介した論文を確認してから選定します。直近の記録と、研究対象、運動課題、EEG指標、解析手法、臨床／基礎／応用の区分が重なりすぎない候補を優先します。

分散の例：

- 健常者／患者／高齢者／アスリート
- 上肢運動／歩行／姿勢制御／全身運動
- 運動学習／運動準備／疲労／リハビリ／BCI
- ERP／時間周波数解析／ERD・ERS／機能的結合／デコーディング
- 基礎研究／臨床研究／技術開発

ただし、分野の多様性を優先することで論文の質や必須条件を大きく損なわないようにします。同じ論文を再度紹介することは避けます。

## 1日分の共有内容

共有は日本語で行います。専門用語は必要に応じて英語表記を併記します。抄録を主な根拠として簡潔にまとめ、本文を確認できる場合は、抄録だけでは判断できない情報を本文で補います。抄録や本文にない内容を推測で補わず、不明な点は不明と明記します。

### 文献情報

- 論文タイトル（原題）
- 著者名
- 出版年
- ジャーナル名
- DOIまたは論文ページへのリンク
- 公開日（確認できる場合）

### メインメッセージ

論文から得られる最も重要な知見を、日本語1文で示します。

### 検索用キーワード

あとから該当論文を探しやすくするため、論文ごとにその研究を表すキーワードを3つ設定し、スライド内に記載します。単語に限定せず短いフレーズでも構いませんが、一覧性と検索性を保つため、できるだけ簡潔な表現にします。

1. **メソッド・指標**：研究で中心的に用いられた計測手法または解析指標（例：`EEG`、`ERD`、`ERP`）
2. **研究テーマ・メッセージ**：研究対象となる現象、機能、メカニズムなど（例：`反応メカニズム`、`長期記憶`、`ワーキングメモリ`、`可塑性`）
3. **研究テーマ・メッセージ**：2つ目とは異なる観点から研究を特徴づける短い表現

キーワードは論文のタイトル、抄録、本文の内容に基づいて選び、論文中で裏付けられない語や、研究内容を過度に一般化した語は使用しません。同じ概念には可能な限り同じ表記を使い、過去のスライドを横断して検索しやすくします。

### 要約

以下の各項目を、原則1〜2文でまとめます。

- **目的**：何を明らかにしようとした研究か
- **手法**：対象者、課題・介入、EEG計測、主要な解析手法など
- **結果**：主要な結果と、その結果に対応するFigure番号（確認できる場合）
- **考察**：著者が結果をどのように解釈し、どのような意義を示したか

Figureを紹介する場合は、本文または図説明で対応関係を確認します。Figure画像をスライドへ掲載する際は、アクセス可否と著作権上の扱いを確認し、出典を明記します。画像を利用できない場合は、Figure番号と結果の説明だけを記載します。

## Google Driveへの記録

### 保存先

Google Driveの次のフォルダを使用します。

`マイドライブ → 牛山研究会 → 論文一覧 → 毎日論文チェック`

- [毎日論文チェック](https://drive.google.com/drive/folders/1J-M8UVLcm5oAW0jMCey2Dc340f8xCLp8)
- [文献まとめテンプレート](https://docs.google.com/presentation/d/1bJdl2tyNfk4T8Pe5-DXUls-Rrv71h1eSMLeij5jjRe0/edit)

2026年8月12日の確認時点では、指定フォルダ内に「文献まとめテンプレート」のみが存在しています。

### 月次ファイル

- 月ごとにGoogleスライドを1ファイル作成します。
- ファイル名は `YYYY年M月` とします（例：`2026年8月`）。
- 当月のファイルがすでにある場合は、新規作成せず、そのファイルを使用します。
- 月が変わった場合は、テンプレートに基づいて新しい月次ファイルを作成します。

### 日次追記

- 1論文につき、新しいスライドを1枚追加します。
- 既存スライドは上書き、置換、削除しません。
- 「文献まとめテンプレート」のレイアウトと書式を基準にします。
- テンプレートの既存1枚を複製し、プレースホルダーの内容を当日の論文情報へ置き換える方法を基本とします。
- テンプレート自体は編集しません。
- 追記前に、同日の論文や同一DOIがすでに記録されていないか確認します。
- 追記後に、スライド枚数、追加位置、表示崩れ、リンク、文字切れを確認します。

テンプレートには、以下の欄があります。

1. 文献タイトル
2. 著者、出版年、ジャーナル名、文献リンク
3. 検索用キーワード3つ
4. 目的
5. 手法
6. 結果
7. 考察

検索用キーワードは、あとから一覧・検索しやすいよう毎回同じ位置と表記形式で配置します。メインメッセージは、タイトル直下または本文領域の先頭に、テンプレートの見た目を損なわない形で配置します。情報量が多い場合は文章を簡潔に調整し、無理に小さい文字へ縮小しません。

## 編集時の安全ルール

- 指定フォルダ内のファイルは、確認のために読み取って構いません。
- 編集対象は、その月の月次スライドに追加する新規スライドだけです。
- 「文献まとめテンプレート」およびその他のファイルは、絶対に編集、移動、名称変更、削除しません。
- 月次ファイルを作る際はテンプレートのコピーを利用し、元ファイルを変更しません。
- 書き込み前に対象フォルダ、対象ファイル名、ファイルID、現在のスライド数を確認します。
- 書き込み後は対象ファイルを再取得し、既存スライドが保持され、新しいスライドが1枚だけ追加されたことを確認します。
- 同名ファイルが複数ある場合や対象を一意に特定できない場合は、書き込まずユーザーへ確認します。
- Google Driveへ接続できない場合や権限が不足している場合は、書き込みを試行し続けず、ユーザーへ接続または権限の確認を依頼します。

## 日次ワークフロー

1. 「論文チェック」スレッド内で、指定されたトリガーメッセージを確認する。
2. このREADMEの最新版を読み、探索・共有・保存のルールを確認する。
3. 当月の月次スライドと過去の紹介内容を読み取り、重複と最近のカテゴリーを確認する。
4. 直近6か月を中心に、英語の脳科学・神経科学論文を複数の情報源で幅広く検索する。
5. ジャーナル水準、運動との関連、EEGの使用という順序で候補を絞る。
6. 候補の書誌情報、公開日、抄録、DOI、研究内容を一次情報で確認する。
7. 最近の紹介分野との偏りも考慮し、最適な論文を1本選ぶ。
8. 日本語で文献情報、メインメッセージ、検索用キーワード3つ、目的、手法、結果、考察を作成する。
9. 当月の月次スライドがなければ、テンプレートのコピーから作成する。
10. 月次スライドの末尾へ、新しいスライドを1枚だけ追加する。
11. 保存後にファイルと追加スライドを再確認し、結果をユーザーへ共有する。
